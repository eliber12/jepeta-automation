# Jepeta Automation

Production automation for the Telegram channel [@jepeta_tools](https://t.me/jepeta_tools).

## Runtime
- Netlify Functions
- Netlify Scheduled Functions
- Netlify Blobs
- Gemini API
- Telegram Bot API

## Required secrets
- `TELEGRAM_BOT_TOKEN`
- `GEMINI_API_KEY`

Do not commit secrets to this repository.
