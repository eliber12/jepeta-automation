## Listing-safe description

Jepeta Risk Guard is a fail-closed pre-trade risk guard for Base agents. It accepts one exact Base ERC-20 contract address and returns machine-readable PASS, WARN, or BLOCK screening with risk signals, source status, data quality, and timestamps.

Screening only. No wallet connection, signatures, trade execution, audit guarantee, or investment recommendation.

Submission targets, review status, campaign parameters, blockers, and internal workflow state are intentionally excluded from this public file.
